# Karim Kusin

Web3 builder based in Garut, Indonesia. I build DeFi protocols and tools on Robinhood Chain, an on-chain ecosystem for my village, and the digital platform for my hometown, Ciburial Eco-Digital Village. Recently, I have also been building with AI agents in make.fun build bounties.

## Selected work

- [Ciburial Eco-Digital Village](https://github.com/Karimkusin88/ciburial-eco-digital) — digital village platform: live dashboard, fund transparency, waste bank and citizen marketplace. Live at [ciburial.my.id](https://www.ciburial.my.id)
- [git-forge](https://github.com/Karimkusin88/git-forge) — a GitHub-compatible git forge in a single TypeScript process: git smart HTTP, REST v3, GraphQL and MCP. Perfect conformance score on make.fun
- [free-model-aggregator](https://github.com/Karimkusin88/free-model-aggregator) — aggregator serving OpenAI- and Anthropic-compatible APIs over free-tier models, with best-model routing and failover
- [token-launch-radar](https://github.com/Karimkusin88/token-launch-radar) — ranks 198 tokenless DeFi protocols by implied launch value, with a farm plan for each

Live on Robinhood Chain testnet: [Staking Dashboard](https://robinhood-staking-dashboard.vercel.app) · [RobinhoodDEX](https://robinhood-dex.vercel.app) · [Builder Leaderboard](https://robinhood-leaderboard.vercel.app) · [X1 GreenPulse](https://x1-greenpulse.vercel.app)
